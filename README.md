# Finpedia｜普通人也能看懂的中文金融百科

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Finpedia 是一个面向金融零基础用户、金融学生和从业者的中文金融知识平台。它保留专业金融知识的完整性，同时先用日常生活建立直觉，让没有学过经济学、会计或金融的人也能理解概念。

> **核心理念：不是把专业金融知识删掉，而是先通过买房、买菜、工资、存钱、信用卡、开店、买手机等生活场景把金融概念讲懂，再补充专业知识。**

在线体验：[Finpedia GitHub Pages](https://liang89205.github.io/Finpedia/)

## 项目目标

Finpedia 希望成为“金融知识搜索引擎 + 金融百科 + 金融学习平台”。用户既可以搜索一个陌生术语，也可以按照知识树系统学习，还能通过相关知识不断延伸阅读。

每个知识页遵循统一的理解顺序：

1. 生活中的故事；
2. 一句话大白话；
3. 金融概念和运行机制；
4. 数字案例与计算；
5. 专业定义、公式和市场应用；
6. 风险、误区、比较与相关知识。

## 当前主要功能

- **全局搜索**：支持中文、英文、缩写、别名、相关词和模糊匹配。
- **金融知识树**：32 个一级分类、534 个独立知识点，可继续扩展。
- **生活化讲解**：通过工资、房贷、信用卡、买菜、开店等场景建立直觉。
- **分层阅读**：从“30 秒看懂”逐步进入机制、公式和专业内容。
- **知识地图**：展示分类结构和知识之间的上下级关系。
- **关联知识网络**：每个页面自动推荐相关概念，支持自由学习路径。
- **个人与家庭金融**：覆盖工资、社保、养老金、存款、信用卡、房贷、保险和家庭现金流等内容。
- **普通人的一天**：从收到工资、扫码支付、汇率、信用卡、房贷到货币基金，解释生活中的金融系统。
- **互动工具**：包含 K 线、杠杆和技术指标等交互式学习入口。
- **响应式界面**：支持桌面端和移动端，并提供深浅色显示。

## 金融知识分类

当前知识体系包含但不限于：

- 股票、债券、基金、ETF、指数；
- 外汇、CFD、期货、期权、永续合约和其他衍生品；
- 加密货币、大宗商品、黄金、房地产和 REITs；
- 银行与信贷、保险、证券市场、金融机构和金融监管；
- 基本面分析、技术分析、量化金融和金融数学；
- 宏观经济、资产管理、投资组合、风险管理和交易策略；
- 个人与家庭金融，包括工资、税、社保、养老金、存款、信用卡、贷款、保险和家庭财务管理。

## 技术特点

- 原生 HTML、CSS 和 JavaScript，无框架依赖；
- 纯静态部署，不需要数据库或 API Key；
- 数据驱动：分类与知识点由 `data.js` 统一管理；
- 生活化内容由 `plain-content.js` 的规则和条目覆盖生成；
- 使用 Hash Router，适合静态托管和 GitHub Pages；
- GitHub Actions 自动部署 `dist/` 到 GitHub Pages。

## 安装与本地运行

项目没有第三方运行依赖。你只需要 Git 和一个本地静态文件服务器。

### 1. Clone 项目

```bash
git clone https://github.com/LIANG89205/Finpedia.git
cd Finpedia
```

### 2. 启动本地服务器

如果电脑已安装 Python 3：

```bash
python3 -m http.server 8080 --directory dist
```

Windows 也可以尝试：

```powershell
py -m http.server 8080 --directory dist
```

然后在浏览器打开：

```text
http://localhost:8080
```

无需执行 `npm install`。不建议直接双击 `index.html`，使用本地服务器可以避免浏览器对本地文件的限制。

## 项目目录结构

```text
Finpedia/
├─ .github/
│  └─ workflows/
│     └─ pages.yml          # GitHub Pages 自动部署

├─ CONTRIBUTING.md
├─ LICENSE
└─ README.md
```

## 如何更新内容

### 新增或修改知识点

1. 在 `dist/data.js` 中新增或修改分类、分组与知识条目。
2. 在 `dist/plain-content.js` 中补充对应的生活故事、数字案例、误区、比较和专业内容。
3. 如果需要新的交互或页面结构，修改 `dist/app.js`。
4. 如果需要调整视觉表现，修改 `dist/styles.css`。
5. 本地启动服务器并检查搜索、页面链接和移动端布局。

### 基础语法检查

```bash
node --check dist/data.js
node --check dist/plain-content.js
node --check dist/app.js
```
